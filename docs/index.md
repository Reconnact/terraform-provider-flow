# flow Provider

Manages compute, kubernetes and mac bare metal resources on the [Flow Swiss](https://flow.swiss/) cloud.

Needs Terraform 1.11 or later.

## Example Usage

```terraform
terraform {
  required_providers {
    flow = {
      source = "flowswiss/flow"
    }
  }
}

provider "flow" {
  # or leave it out and set FLOW_TOKEN
  token = var.flow_token
}
```

An argument that is not set comes from the environment: `FLOW_TOKEN`, `FLOW_ENDPOINT`, `FLOW_RETRY_TIMEOUT`.
